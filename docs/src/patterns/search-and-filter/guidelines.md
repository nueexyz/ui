## 함께 바뀌어야 하는 상태

폼은 `query`와 `status`를 저장하고 결과 목록은 `applied`만 읽습니다. 적용하면 앞뒤 공백을 지운 검색어와 상태를 `applied`에 복사합니다. 초기화하면 양쪽을 함께 갱신합니다. 조건을 수정하는 동안에는 변경 사항이 아직 결과에 반영되지 않았다고 안내합니다.

`FieldLabel`로 입력 이름을 유지합니다. 상태 하나를 고르므로 `Select`를 사용합니다. 짧은 선택지 세 개에 `Combobox`의 검색은 불필요합니다. 이름과 상태 하나는 일반 목록으로 보여 주고, 여러 열을 비교해야 할 때 `Table`을 선택합니다.

결과 수와 적용 조건을 하나의 상태 알림으로 전달합니다. 목록이 바뀌어도 초점은 옮기지 않으며 기본 폼 동작으로 Enter 제출을 지원합니다. 항목 선택만으로 반영하지 않고 제출할 때만 입력 중인 조건을 적용합니다.

## 서버 결과로 확장하기

요청을 시작하면 마지막으로 성공한 목록과 적용 조건 요약을 유지하고, 로딩 중에는 이전 결과임을 알립니다. 새 결과가 성공할 때까지 요청한 조건을 별도로 추적합니다. 실패하면 입력을 보존하고 갱신 실패와 요청한 조건으로 재시도할 방법을 제공합니다. 요청 실패를 “결과 없음”으로 표시하지 않습니다.

이전 요청이 끝나기 전에 새 요청을 보낼 수 있다면 이전 요청을 취소하거나 그 응답을 무시합니다. 새 조건을 적용할 때 페이지 번호를 초기화합니다. 결과를 공유해야 한다면 적용 조건을 URL에 담고 브라우저 탐색 시 폼과 결과를 함께 복원합니다.

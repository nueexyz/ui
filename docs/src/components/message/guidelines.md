## 사용 가이드

### 사용할 때

보낸 사람·내용·부가 정보를 묶는 대화 항목에 사용합니다. 페이지 수준 상태 컴포넌트가 아닙니다. 지속적인 안내는 [Banner](?path=/docs/components-banner--docs), 짧은 작업 결과는 Toast를 사용합니다.

### 구성과 정렬

`MessageContent`에 본문을, `MessageFooter`에 시간이나 전송 상태 같은 보조 정보를 넣습니다. `Bubble`은 말풍선 표현을, `Message`는 대화 항목의 묶음을 담당합니다. 연속된 메시지에서 아바타를 생략해도 보낸 사람을 식별할 수 있게 합니다.

> 대화 참여자에 맞게 `align="start"`와 `align="end"`를 일관되게 사용합니다. 정렬만으로 보낸 사람을 구별하지 않습니다. 문서의 읽기 순서를 시간 순서로 유지하고 새 메시지 하나가 왔을 때 대화 전체를 다시 읽어 주지 않습니다.

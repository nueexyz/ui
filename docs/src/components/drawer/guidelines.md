## 사용 가이드

### 사용할 때

목록 필터처럼 보조 컨트롤이나 범위가 분명한 작업을 가장자리 패널에 담을 때 사용합니다. 작고 중앙에 집중할 작업은 [Dialog](?path=/docs/components-dialog--docs), 독립적인 탐색이 필요한 작업은 페이지를 선택합니다.

### 위치보다 상호작용 먼저 결정하기

`Drawer`는 기본적으로 모달입니다. 투명한 배경은 모양을 바꾸며 배경 조작을 허용하지는 않습니다. 패널을 연 채 페이지를 조작해야 한다면 `modal={false}`와 `overlay="none"`을 사용하고 필요한 컨트롤을 가리지 않는지 확인합니다.

배치와 읽을 공간에 맞게 열리는 방향을 정합니다. 모바일에서 모든 `Dialog`를 하단 `Drawer`로 자동 대체하지 않습니다. 화면 너비에 따라 표현을 바꾼다면 입력한 값이 유지되고 컴포넌트가 교체될 때 초점을 잃지 않게 합니다.

### 닫기와 제스처

> `DrawerClose`로 보이는 닫기나 취소 행동을 제공합니다. 스와이프 핸들과 별개로 버튼으로도 닫을 수 있게 합니다. 닫기를 허용하기 전에 저장하지 않은 값의 처리 방식을 정합니다. 좁은 화면에서 키보드 접근과 긴 콘텐츠를 확인합니다.

### 구성과 스타일

`DrawerContent`가 포털·오버레이·팝업과 콘텐츠 영역을 내부에서 구성합니다.
`DrawerPopup`으로 별도 감싸지 않습니다. `xstyle`은 자식을 직접 감싸는 영역에
적용되어 `gap`과 내부 배치를 조절합니다. 나머지 속성과 `ref`는 팝업에 전달됩니다.
오버레이와 스와이프 핸들은 `Drawer`의 `overlay`, `showSwipeHandle`로 설정합니다.

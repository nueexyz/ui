## Usage guidelines

### When to use

Use `Checkbox` for an independent choice that can be selected or cleared, or for multiple selections in a group. Use [Radio Group](?path=/docs/components-radio-group--docs) when exactly one option is selected, and [Switch](?path=/docs/components-switch--docs) for an immediately applied on/off setting.

### Labels and grouping

Describe what selecting the checkbox means. Keep that label stable when its state changes. Group related choices under a shared name and explain whether they apply immediately or on submission.

> Use a horizontal `Field` for the checkbox and label. For supporting text, use `FieldContent`; align with the title's first line rather than the whole text block. Associate the visible label with the checkbox through its ID.

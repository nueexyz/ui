## 사용 가이드

### 사용할 때

배송 방법처럼 차이를 비교하며 하나를 선택할 때 사용합니다. 선택지의 차이가 결정에 영향을 주면 항목을 펼쳐 보여 줍니다. 작은 목록으로 충분하면 [Select](?path=/docs/components-select--docs), 서로 독립적인 선택이면 `Checkbox`를 사용합니다.

### 선택지와 기본값

그룹 이름과 구별되는 항목 이름을 제공합니다. 가격·시간·결과의 차이가 있다면 짧은 설명을 붙입니다. 사용자가 직접 결정해야 하는 항목은 기본값으로 미리 선택하지 않습니다. 선택이 필수가 아니고 해제할 필요가 있다면 “없음” 항목을 명시합니다.

> 관련 항목을 함께 배치하고 그룹의 키보드 동작을 유지합니다. 독립적으로 제어하는 체크박스로 단일 선택을 만들지 않습니다.

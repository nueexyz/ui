# nuée 기본 원칙

화면을 만들 때 값부터 고르지 않고 사용자의 과제, 정보의 우선순위, 상호작용을 먼저 정합니다. 이 문서는 nuée에서 화면을 구성할 때 적용할 기준입니다.

## 적용 순서

1. 사용자가 이 화면에서 마쳐야 하는 작업을 한 문장으로 정합니다.
2. 정보를 제목·본문·보조 설명으로 나누고 주요 행동을 하나 정합니다.
3. 기존 컴포넌트의 사용법과 지원하는 속성을 확인합니다.
4. 의미에 맞는 색상과 크기·간격·모션 토큰을 선택합니다.
5. 빈 화면, 로딩, 성공, 실패, 긴 콘텐츠, 키보드 사용을 확인합니다.

## 문서를 고르는 기준

| 결정할 것                             | 읽을 문서                    |
| ------------------------------------- | ---------------------------- |
| 어떤 값과 이름을 쓸까                 | 디자인 토큰, 색상, 글자      |
| 정보를 어떻게 묶을까                  | 레이아웃, 간격, 모서리, 높이 |
| 조작과 결과를 어떻게 알릴까           | 상태, 움직임, 피드백         |
| 다양한 사용자가 읽고 조작할 수 있을까 | 접근성, 다국어 설계          |
| 무엇을 어떻게 말할까                  | 말투와 어조, 문장 작성       |

## 기준과 구현의 관계

이 문서의 권장 배치는 새로운 화면을 위한 기본 선택입니다. 컴포넌트가 이미 정한 글자 크기와 정렬을 화면마다 덮어쓰지 않습니다. 예외가 필요하면 이유와 적용 범위를 먼저 적습니다.

## LLM으로 화면 만들기

[LLM용 전체 규칙](llms-full.txt)을 먼저 읽고, 만들 화면에 필요한 주제와 컴포넌트 문서를 확인하도록 요청합니다. 이 저장소의 `AGENTS.md`는 해당 규칙 파일을 안내합니다. 다른 프로젝트에서는 규칙의 경로를 요청에 명시해야 하며, 문서가 있다는 이유만으로 모든 LLM이 자동으로 읽는 것은 아닙니다.

## 참고 자료

주제 구성은 [SEED Foundations](https://seed-design.io/foundations)를 참고했습니다. 토큰과 동작은 nuée 구현을 기준으로 합니다. SEED의 브랜드 규칙이나 지원 범위를 nuée의 것으로 간주하지 않습니다.

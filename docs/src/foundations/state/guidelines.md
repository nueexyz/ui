# 상태

상태는 지금 조작할 수 있는지, 무엇이 선택되어 있는지, 작업이 진행 중인지 알려줍니다.

## 상태를 구분하는 기준

| 상태             | 표현                                          |
| ---------------- | --------------------------------------------- |
| Hover·Pressed    | 입력 중임을 알려주는 일시적인 반응            |
| Focus visible    | 키보드가 가리키는 위치                        |
| Selected·Checked | 사용자가 정한 지속되는 선택                   |
| Disabled         | 현재 조건에서는 실행할 수 없음                |
| Loading          | 요청이 진행 중임                              |
| Error            | 작업을 마치지 못했고 수정이나 재시도가 필요함 |

`interactionPressed`는 누르는 동안만 적용합니다. `interactionSelected`는 선택된 상태를 유지할 때 사용합니다. 하나로 합치면 선택 여부와 입력 반응이 혼동됩니다.

## 구현 기준

컴포넌트의 `disabled`, `checked`, `aria-invalid` 등 의미가 있는 속성을 먼저 사용합니다. 겉모양만 비활성으로 만들고 클릭을 계속 받지 않게 합니다. 로딩 중에는 중복 제출을 막되 어떤 작업이 진행 중인지 알려줍니다.

## 확인할 것

기본·호버·누름·포커스·비활성 상태를 라이트·다크 모드에서 확인합니다. 선택과 포커스가 함께 존재하는 경우도 검사하고, 비활성 이유가 필요한 화면에는 이유를 가까이 제공합니다.

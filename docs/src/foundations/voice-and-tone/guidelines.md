# 말투와 어조

nuée를 사용하는 제품의 기본 문장은 짧고 구체적이며 사용자를 탓하지 않습니다. 제품 고유의 문체가 있다면 그 안에서도 이 원칙을 유지합니다.

## 상황별 톤

| 상황                | 기준                          |
| ------------------- | ----------------------------- |
| 평상시 안내         | 필요한 정보부터 담담하게 설명 |
| 성공                | 무엇이 완료되었는지 짧게 확인 |
| 오류                | 문제와 다음 행동을 함께 제시  |
| 되돌릴 수 없는 행동 | 결과와 대상을 분명히 설명     |

성공 때마다 과장된 축하를 하거나, 오류 때 장황하게 사과해 해결 방법을 뒤로 미루지 않습니다. 기술적인 내부 표현을 사용자 문장으로 그대로 내보내지 않습니다.

## 예시

- 권장: “변경사항을 저장했어요.”
- 권장: “저장하지 못했어요. 연결을 확인하고 다시 시도해 주세요.”
- 피할 표현: “알 수 없는 에러 코드 발생!”

한 화면에서 존댓말의 정도와 문장 끝맺음을 섞지 않습니다. 법적 동의나 금전적 결과를 설명하는 문장은 친근함보다 정확성을 우선하고, 제품 담당자가 내용을 확인해야 합니다.

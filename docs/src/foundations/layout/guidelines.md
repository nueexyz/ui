# 레이아웃

레이아웃은 관련 정보와 행동의 관계를 드러내야 합니다. 시각적으로 같은 줄에 있다는 이유만으로 서로 관련 없는 항목을 묶지 않습니다.

## 컴포넌트 선택

| 상황                          | 먼저 검토할 컴포넌트   |
| ----------------------------- | ---------------------- |
| 제목·설명·보조 행동이 있는 행 | Content Row            |
| 이름·설명·오류가 있는 입력    | Field                  |
| 독립된 정보 묶음              | Card                   |
| 짧은 맥락 메뉴·선택           | Popover, Dropdown Menu |
| 집중이 필요한 작업            | Dialog, Drawer         |
| 결과 목록·비교 가능한 값      | Table                  |

## 폭과 간격

짧은 입력 묶음에는 `sizeVars.contentSm`, 읽기 영역에는 `contentMd` 등을 시작점으로 검토합니다. 고정 폭을 강제하지 않고 좁은 화면에서 사용 가능한 폭을 넘지 않게 합니다. 관계에 따른 간격은 Spacing 문서를 따릅니다.

## 첫 줄 정렬

Content Row의 제목과 액션은 첫 줄 기준선에 맞춥니다. Checkbox와 FieldContent가 함께 있으면 제목 첫 줄에 정렬합니다. 설명의 줄 수가 바뀌어도 사용자가 보정용 위·아래 여백을 추가하지 않게 합니다.

## 좁은 화면

충분한 폭이 없으면 보조 행동을 다음 줄로 보내거나 관련 메뉴에 모읍니다. 기본 행동을 숨기지 않습니다. 고정 높이, 넘치는 폭, 가로 스크롤을 기본 해결책으로 사용하지 않습니다.

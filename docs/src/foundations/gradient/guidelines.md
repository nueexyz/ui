# 그라데이션

그라데이션은 현재 nuée의 공통 의미 토큰으로 정의되어 있지 않습니다. 기본 UI는 단색 표면과 의미 색상으로 구성합니다.

## 사용할 수 있는 상황

브랜드 소개나 콘텐츠의 장식 영역처럼 구체적인 목적이 있고, 단색으로는 표현하기 어려운 경우에 화면 범위를 한정해 검토합니다. 반복 사용이 확인되기 전에는 `gradientVars` 같은 존재하지 않는 공통 API를 가정하지 않습니다.

## 사용하지 않을 상황

입력 오류, 버튼의 선택 상태, 비활성 상태를 표현하려고 그라데이션을 추가하지 않습니다. 해당 상태는 기존 색상 토큰과 컴포넌트 속성으로 표현합니다.

## 확인할 것

텍스트 뒤에 사용한다면 가장 밝고 어두운 위치 모두에서 읽을 수 있어야 합니다. 테마별 결과와 이미지가 없는 경우를 확인하고, 장식 때문에 핵심 행동이 묻히지 않게 합니다. 새로운 공통 패턴으로 채택할 때 시작·끝 색, 방향, 적용 대상과 대비 검증을 함께 정합니다.

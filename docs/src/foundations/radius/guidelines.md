# 모서리

모서리는 같은 역할의 요소가 같은 계열로 보이도록 선택합니다. 둥근 모서리 자체로 행동의 중요도를 표현하지 않습니다.

## 선택 기준

| 용도                  | 권장 시작점               |
| --------------------- | ------------------------- |
| 작은 컨트롤·배지      | `radiusVars.sm`           |
| 일반 표면             | `radiusVars.md`           |
| 큰 패널·미리보기 영역 | `radiusVars.lg` 또는 `xl` |
| 원형 아바타·필 형태   | `radiusVars.full`         |

기존 컴포넌트에는 이미 선택된 모서리가 있습니다. 화면을 맞춘다는 이유로 컴포넌트마다 별도 값을 덮어쓰지 않습니다. 위 표는 새로운 표면을 설계할 때의 출발점입니다.

## 중첩 영역

안쪽 요소와 바깥 표면의 모서리가 어색하게 겹치는지 실제 간격과 함께 봅니다. 같은 값을 기계적으로 모든 중첩 표면에 적용하거나 새로운 숫자를 반복 추가하지 않습니다.

## 확인할 것

이미지·포커스 링·팝업이 잘리지 않는지 확인합니다. 둥근 영역을 만들려고 무조건 `overflow: hidden`을 추가하면 포커스 표시나 메뉴가 잘릴 수 있으므로 대상 콘텐츠를 먼저 확인합니다.

# 접근성

접근성은 완료 후 별도로 추가하는 장식이 아니라 컴포넌트를 선택하고 콘텐츠를 배치할 때의 기본 조건입니다.

## 작성 기준

버튼은 Button, 입력은 Input과 Field, 선택은 Checkbox나 Radio Group처럼 의미가 있는 요소를 사용합니다. 클릭 가능한 `div`로 기본 컴포넌트를 대체하지 않습니다.

| 확인할 것 | 방법                                                           |
| --------- | -------------------------------------------------------------- |
| 이름      | 입력에는 레이블, 아이콘 버튼에는 접근 가능한 이름 제공         |
| 키보드    | Tab 순서와 Enter·Space·Escape 동작 확인                        |
| 포커스    | 현재 위치가 보이고 모달 종료 후 적절한 위치로 복귀하는지 확인  |
| 상태      | 색 외에 문장·아이콘·선택 속성으로도 전달                       |
| 크기      | 표시 크기와 누르는 영역을 분리하고 `sizeVars.touchTarget` 검토 |
| 확대·모션 | 200% 확대, 좁은 화면, 모션 줄임에서 내용과 행동 유지           |

## 오류 안내

오류는 해당 입력 가까이에 두고 무엇을 고칠지 설명합니다. 화면 위 Toast 하나만으로 입력 오류를 알리지 않습니다. 비활성 버튼만 보여 주지 말고 사용자가 조건을 충족하는 방법을 설명합니다.

## 검증 범위

자동 접근성 검사는 출발점입니다. 자동 검사 통과를 전체 접근성 보장으로 표현하지 않습니다. 실제 키보드 조작, 화면 낭독기의 이름·역할·상태, 사용한 색상 조합을 별도로 확인합니다.

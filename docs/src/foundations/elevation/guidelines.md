# 높이

높이 표현은 화면의 관계를 설명할 때 사용합니다. 단순히 눈에 띄게 하려고 그림자와 겹침 값을 높이지 않습니다.

## 선택 기준

| 관계                     | 선택                                         |
| ------------------------ | -------------------------------------------- |
| 같은 면의 묶음           | 여백·경계선, 필요할 때 `shadowVars.subtle`   |
| 작은 떠 있는 메뉴·팝오버 | `shadowVars.floating`                        |
| 모달 표면                | `shadowVars.overlay`                         |
| 모달 배경과 내용         | `layerVars.modalBackdrop`, `layerVars.modal` |
| 팝업·알림                | `layerVars.popup`, `layerVars.notification`  |

컴포넌트가 관리하는 포털과 레이어를 먼저 사용합니다. 메뉴가 가려진다고 임의로 `z-index: 9999`를 추가하지 말고 부모의 겹침 맥락과 포털 위치를 확인합니다.

## 사용 예

짧은 보조 선택은 Popover나 Dropdown Menu, 완료 전에 집중해야 하는 흐름은 Dialog나 Drawer를 검토합니다. 그림자는 모달의 키보드 포커스 관리나 배경 차단을 대신하지 않습니다.

## 확인할 것

라이트·다크 모드의 경계와 그림자를 모두 확인합니다. Toast를 쌓을 때 글자와 테두리까지 축소해 흐려지게 만들지 않습니다. 새로운 레이어 역할이 필요하면 기존 순서와 상호작용을 먼저 문서화합니다.

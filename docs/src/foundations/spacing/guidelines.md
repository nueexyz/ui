# 간격

간격은 요소 사이의 관계를 나타냅니다. 관련 있는 항목은 가깝게, 다른 작업 묶음은 더 멀리 배치합니다.

## 선택 기준

| 관계                    | 권장 시작점                    |
| ----------------------- | ------------------------------ |
| 아이콘·짧은 레이블 내부 | `space1`, `space2`             |
| 한 행의 요소·필드 내부  | `space2`, `space3`             |
| 관련된 필드·행 사이     | `space3`, `space4`             |
| 카드·패널 내부          | `space4`, `space6`             |
| 다른 섹션 사이          | `space8`, `space10`, `space12` |

모든 값은 `spacingVars`에서 선택합니다. 반 단계인 `space0_5`는 작은 경계 보정에 한정하고, 새로운 화면의 큰 배치를 맞추는 기본값으로 쓰지 않습니다.

## 사용 예

제목과 설명 사이보다 서로 다른 설정 그룹 사이의 간격을 크게 둡니다. 좁은 화면에서는 패널의 바깥 여백을 줄여도 입력 레이블과 오류 안내가 붙어서 읽히지 않게 내부 관계를 유지합니다.

## 피할 것

어긋난 정렬을 임의의 여백으로 가리지 않습니다. 기준선·줄 높이·컨트롤 크기·레이아웃 속성을 먼저 확인합니다. 동일한 관계에 여러 숫자를 섞지 말고 화면 전체에서 같은 토큰을 유지합니다.
